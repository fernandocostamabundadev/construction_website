# Construct — Construção com propósito

Site responsivo de demonstração para serviços de construção, renovação e manutenção, com conteúdo em português de Portugal.

## Funcionalidades

- Apresentação de serviços e projetos concluídos.
- Navegação adaptada a telemóveis, com suporte para teclado.
- Animações suaves de entrada e interação.
- Respeito pela preferência do sistema para movimento reduzido.
- Formulário de demonstração com confirmação local.

## Executar

Abra `index.html` num navegador. Não é necessária instalação.

## Nota sobre o formulário

O formulário serve apenas para demonstrar a interação na página. Não envia nem guarda dados. Para receber pedidos reais, será necessário ligá-lo a um serviço de formulários.
